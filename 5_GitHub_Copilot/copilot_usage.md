# GitHub Copilot Usage

## Project
Blood Bank Inventory & Emergency Donor Matcher

## Purpose
GitHub Copilot was used as an AI-assisted development tool to support the implementation and testing of the project.

## Example Tasks

### 1. Blood Group Matching
Prompt:
> Generate a function to check whether a donor blood group is compatible with a requested blood group.

### 2. Donor Eligibility
Prompt:
> Generate logic to verify donor eligibility based on the minimum donation gap and eligibility status.

### 3. Blood Inventory
Prompt:
> Generate a function to search available blood units by blood group and availability status.

### 4. Testing
Prompt:
> Generate test cases for blood group matching, donor eligibility, and blood unit reservation.

## Review
All Copilot-generated suggestions should be reviewed and tested before being used in the project.
